Put this file on GitHub Pages

  1. On github.com, create a new Public repository (for example day-trading-dashboard) — or reuse one you already have.
  2. Upload this page into it as index.html at the repository root (Add file → Upload files). This single file is the whole dashboard — nothing else to upload.
  3. In the repository: Settings → Pages → under “Build and deployment”, pick Deploy from a branch, branch main, folder / (root), then Save.
  4. GitHub publishes it at https://<your-username>.github.io/day-trading-dashboard/ — usually live within a minute or two. Open that address on any device; no sign-in needed to view it.
