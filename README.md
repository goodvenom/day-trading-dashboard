# Day Trading Dashboard — Static Snapshot

Static GitHub Pages version of the Day Trading Dashboard (Bitcoin, Gold via GC=F, and US stocks).

- Analysis runs entirely in the browser using the same EMA + Chandelier method as the original dashboard.
- Data is a labeled Yahoo Finance 15-minute snapshot captured Sat 31 Oct 2026, 10:31 IST — it does NOT update live. A rebuild refreshes the numbers.
- Budget/risk sizing and the PASS/BLOCK risk gate are recomputed in the browser for any budget/risk choice.
- Runs on this page are not saved to the original dashboard's history.
- Prices are Yahoo delayed data, not live broker prices. TradingView/broker stays primary.
